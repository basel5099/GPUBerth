# Contributing

Issues and pull requests are welcome, especially install reports from other hardware.

- Run `python3 tests/test_scheduler.py` and keep it passing.
- Add a test for each scheduling change.
- Never commit real tokens, keys, addresses or config files. Use documentation addresses such as
  `192.0.2.x`, `203.0.113.x` and `example.com`.
- Report security problems privately. See [SECURITY.md](SECURITY.md).
